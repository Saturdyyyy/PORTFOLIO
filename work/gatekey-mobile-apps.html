Case study · Mobile UI/UX

GateKey Mobile Apps

Interface design for the Guard, User and Superadmin apps of GateKey, a visitor-management platform.

Visit gatekey.co.in ↗Book a similar project
RoleUI/UX designer
PlatformAndroid & iOS (React Native)
Scope3 role-based apps
ToolsFigma, React Native, REST APIs

Challenge

Visitor management has three very different users. Guards work at the gate, often standing and in a hurry. Residents use the app occasionally and need it to be obvious. Administrators need dense information they can scan quickly. One generic interface would serve none of them well.

My role

I designed the interface for all three apps and worked on connecting the screens to the product's backend APIs.

Solution

  • One shared design system (colours, type, components) so the three apps feel like one product.
  • Each app built around its most frequent task instead of a generic dashboard.
  • Large tap targets, few steps and clear status colours for the Guard app.
  • Scannable lists and summaries for the Superadmin app.

Deliverables

  • Guard, User and Superadmin app interfaces
  • Shared component library
  • Screens integrated with backend APIs

Tools

Figma, React Native (Expo), REST APIs.

Visual proof

Visual proof placeholder: approved screens of the Guard, User and Superadmin apps

Outcome

Three role-based app interfaces delivered under one visual system for a live visitor-management product.
