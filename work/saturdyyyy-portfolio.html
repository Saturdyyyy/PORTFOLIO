Saturdyyyy Portfolio

My original music-themed portfolio, built without frameworks, with a live Spotify integration.

Open the lab →Book a similar project
RoleDesign & development
PlatformWeb
ScopeFront end, API proxy, deployment
ToolsHTML, CSS, JS, Node, Express

Challenge

I wanted a portfolio that felt like a person rather than a template, and an excuse to learn what frameworks usually hide.

My role

Everything: concept, design, front end, the API proxy and deployment.

Solution

  • An album-style structure, a dot-grid Canvas background, a custom cursor and a small catch-the-notes game.
  • A Spotify Web API integration over OAuth 2.0, through a Node/Express proxy on Render, so the browser never sees the client secret.
  • Front end on Vercel and the proxy on Render, both deploying automatically from GitHub.

Deliverables

  • Interactive portfolio site
  • Spotify proxy with now-playing, recent tracks and playback controls

Tools

HTML, CSS, JavaScript, Canvas API, Node.js, Express, OAuth 2.0, Vercel, Render.

Outcome

The site lives on as the Saturdyyyy Lab, and its live Spotify status appears in the footer of this website.
